# PCA Frontend — Minimal Dark Verified

Frontend-only React + TypeScript + Vite prototype for the PCA hackathon concept.

## Run

```bash
npm install
npm run dev
```

Then open http://localhost:5173

## Notes

- No Python, FastAPI, SQLite, or API key is required.
- All data is local mock state.
- Message Page supports Sender/User modes and simulated conversations.
- PCA Assistant page provides a local Wake PCA flow and mock Telugu analysis.
